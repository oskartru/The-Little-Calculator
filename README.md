# The-Little-Calculator

Web Calculator: Project Description

This project is a web calculator built with plain HTML, CSS, and JavaScript, split into three separate files. It supports unary operations (square, cube, modulus, factorial, square root, power) and binary operations (+, −, ×, ÷). It also handles comma-separated lists: sum, average, sort, reverse, and remove elements.

An information field describes each result. A central validation function shows specific error messages, and all errors are logged in a downloadable CSV file. The design is responsive and fully usable with the keyboard.
